## Execution order & dependencies

All five plans are independent — no plan depends on another, and each
touches a disjoint set of lines (001 and 002/005 both touch
`components/slide-thumbnail.tsx` but at different, non-overlapping spots:
001 doesn't touch that file at all — profile-editor.tsx only; 002 touches
the hover-reveal `<div>`s; 005 touches the outer `motion.div`'s `transition`
and the component's props — no conflict). They were implemented in numeric
order (001 → 005) for traceability, not because of a hard dependency.

## Not implemented from the original audit

The four "missed opportunities" (toggle icon crossfade, export success
visual payoff, frame-picker selection transition, landing-page scroll-in
examples) were listed as additive suggestions, not findings, and were not
turned into plans in this pass — revisit with `improve-animations plan
<description>` if desired.
